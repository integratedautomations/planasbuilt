Do

  • Use the icon alone under 120 px wide
  • Use favicon.svg for browsers; it drops the door swings, windows and closet and uses heavier walls for 16 px
  • Use the dark lockup (navy icon) on photos or dark UI
  • Use icon-mono.svg for stamps, engraving and single-color print

Don't

  • Recolor the check anything but redline red
  • Stretch, rotate or add shadows to the mark
  • Set the wordmark in another font; use the outlined SVG
  • Use the light icon on light backgrounds without its rounded square
